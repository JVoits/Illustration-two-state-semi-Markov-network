# Two-state semi-Markov illustration

This repository contains the Monte Carlo simulation and data used for the two-state semi-Markov example.

## Repository Structure

- `MC_Illustration_convergence_semi-Markov_NW_two_states.ipynb`  
  Simulation and plotting notebook.

- `two_state_semimarkov_data.csv`  
  Numerical data generated by the notebook.

The notebook estimates the occupation probability \(p_1(t)=\mathbb P(X_t=1)\) for finite-mean and heavy-tailed waiting-time distributions and compares the results with the theoretical long-time limits.
